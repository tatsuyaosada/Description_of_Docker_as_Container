#### 始めに
ウェブに限らずサーバー構築は様々な方法があるが、こと開発環境として構築する場合、極めて面倒であり、ハードルも高いものが多い。昨今では、例えばPHPなら[XAMPP](https://www.apachefriends.org/jp/index.html)の様なある程度必要なものがバンドルされ、インストールするだけで使える様になるミドルウェアもあるが、多くの場合、コマンドラインや環境PATHの設定等、非常に煩わしい環境構築が求められる。それが TODO::

#### サーバー構築のいくつかの手法
1. サーバーソフトウェアをインストールする専用の物理マシンを用意する（※）
2. クライアント側に仮想マシン[^1] を導入し、サーバーとして扱う
3. レンタルサーバー、クラウドを利用する
4. <strong>コンテナ</strong>を用いる
