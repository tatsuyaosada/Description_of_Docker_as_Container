#### サーバー構築のいくつかの手法とそれぞれの長所/短所
1. サーバーソフトウェアをインストールする専用の物理マシンを用意する
   - 長所：限りなくリリース時に近い、と言うかほぼ同一の開発環境を用意出来る。
   - 短所：そもそもオンプレミス[^1]を開発環境として用いるにはコスト的に現実的ではない。
3. クライアント側に仮想マシン[^2] を導入し、サーバーOSを導入し、開発環境として扱う
   - 長所：PC一台上にで様々な環境が構築出来る
   - 短所：メインOS上に別のOSを<strong>論理的に</strong>[^3] 走らせる事になるので、当然ながら処理にかかるコスト、オーバーヘッドはそれ相応のものになる。
5. レンタルサーバー、クラウドを利用する
6. <strong>コンテナ</strong>を用いる(今回の主題)
