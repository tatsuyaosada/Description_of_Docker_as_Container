#### サーバー構築のいくつかの手法とそれぞれの長所/短所
1. サーバーソフトウェアをインストールする専用の物理マシンを用意する[^1]
   - 長所：限りなくリリース時に近い、と言うかほぼ同一の開発環境を用意出来る 
   - 短所：そもそもオンプレミス[^1]を開発環境として用いるにはコスト的に現実的ではない
3. クライアント側に仮想マシン[^2] を導入し、サーバーとして扱う
4. レンタルサーバー、クラウドを利用する
5. <strong>コンテナ</strong>を用いる(今回の主題)
